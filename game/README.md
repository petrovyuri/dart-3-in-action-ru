# Мечи и Магия

Консольный учебный проект курса [«Dart 3 в действии»](https://stepik.org/course/120892/syllabus). Основа: [архив из урока 8.7](https://stepik.org/media/attachments/lesson/1221751/swords_and_magic-main.zip).

Проект содержит меню, создание персонажа, выбор класса, сохранение и загрузку JSON, асинхронный ввод и режим усиленного персонажа. Боевая система в этом снимке ещё не реализована.

## Запуск

Проверено с Dart 3.11.0.

```sh
dart pub get
dart run bin/main.dart
```

В меню введите `1` для новой игры, `2` для загрузки или `3` для выхода. Во время игры команда `exit` сохраняет персонажа и завершает программу.

Режим усиленного персонажа:

```sh
dart run --define=SUPER_MODE=true bin/main.dart
```

Файл сохранения `playerEntityJson.json` и журнал `swords_and_magic.log` создаются в текущей рабочей папке.

## Проверки

```sh
dart format --output=none --set-exit-if-changed .
dart analyze
dart test
```

При подготовке архива к публикации исправлена проверка пункта меню, сохранения защищены от перезаписи при выходе до начала игры, команда `exit` обрабатывается целой строкой. Версия в `pubspec.yaml` приведена к версии, которую показывает программа. Исходный архив сохранён в рабочем репозитории автора.
