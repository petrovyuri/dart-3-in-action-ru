# 2.6 Мечи и Магия version 0.0.1+1

Проект игры после урока 2.6: лист персонажа. Имя героя вводится с клавиатуры. Название, версия и стартовые характеристики хранятся в константах, а характеристики героя в переменных.

Сначала напишите код сами по описанию в уроке, а потом сравните с этим вариантом.

Требуется Dart SDK 3.14 или новее.

```sh
dart pub get
dart run bin/main.dart
```

Программа попросит ввести имя героя и выведет лист персонажа. Если в терминале Windows русские буквы имени превращаются в непонятные символы, введите имя латиницей.

Папки `lib` и `test` оставлены такими, какими их создал шаблон `dart create`. Тест шаблона запускается командой `dart test`.
