# Dart 3 в действии

Интерактивные примеры и исходный код [курса Юрия Петрова на Stepik](https://stepik.org/course/120892/syllabus).

## Материалы

- [Интерактивные примеры](https://petrovyuri.github.io/dart-3-in-action-ru/) публикуются через GitHub Pages после слияния pull request в `main`.
- [`examples/module-01/`](examples/module-01/) содержит программу из урока **1.4 «Установка и настройка VSCode для работы с языком Dart»**.
- [`game/`](game/) содержит консольную игру «Мечи и Магия» на основе архива урока **8.7**.

Первый модуль ознакомительный, без проверочных вопросов. В демо урока **1.2 «Что такое программирование?»** можно менять порядок действий героя и проследить выполнение алгоритма.

## Запуск примера 1.4

```sh
cd examples/module-01
dart pub get
dart run bin/main.dart
```

Код проверен с Dart 3.11.0. Инструкции для игры находятся в [`game/README.md`](game/README.md).

## Изменения и публикация

Материалы поступают из рабочего репозитория автора через отдельную ветку и pull request. В PR выполняются проверки сайта и кода. После слияния в `main` workflow GitHub Pages публикует папку `docs/`.
