# Публичные материалы курса Dart 3 в действии

- Здесь находятся только сайт интерактивных примеров и исходный код уроков и игры.
- Основной рабочий репозиторий: `petrovyuri/src_dart_3_in_action`, приватный.
- Изменения готовить в рабочем репозитории, затем переносить через его `tools/export_public.py`.
- Публикация выполняется через отдельную ветку и pull request в `main`. Прямой push в `main` запрещён.
- Перед созданием ветки выполнять `git fetch origin` и использовать свежую основную ветку. Сохранять чужие локальные изменения.
- Объяснения, комментарии, ошибки и логи писать на русском. Применять humanizer-ru и правила Sepia; новые тексты писать через sepia-write.
- Заголовки в материалах выравнивать по центру. Первый модуль ознакомительный, без проверочных вопросов.
- После изменений запускать анализаторы, форматирование, тесты и проверку сайта.
- Данные Stepik, тексты полных уроков, ответы к заданиям и рабочие отчёты сюда не переносить.
